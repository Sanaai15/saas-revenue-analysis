# SaaS Revenue & User Metrics Dashboard

## Objective

Analyze SaaS revenue and user data to identify key business metrics, track their dynamics over time, and understand the factors driving changes in revenue and paid users.

## Tools & Technologies

- SQL
- PostgreSQL
- Tableau Public

## Tasks Performed

- Queried and prepared data from PostgreSQL using SQL.
- Calculated key metrics including MRR, Paid Users, ARPPU, Churn Rate, New MRR, Expansion MRR, Contraction MRR and Churned Revenue.
- Built an interactive Tableau dashboard with monthly trends and revenue/user change drivers.
- Added filters by month, user language and age.
- Published the final dashboard to Tableau Public.
